A fast drop-in for csv-reader 1.0.0: reads broken CSV files exactly the way csv-reader does — same columns, rows, and errors for every input — only faster. Single-pass parser in dependency-free JavaScript: bulk scanning with indexOf, one forward-only pointer for the sparse CR, no per-character loops in the hot paths, no regex.

## Run it

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
